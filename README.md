## 🚀 What is this?

This repository is a **personal developer documentation portal** — a centralized hub for notes, cheatsheets, guides, and reference materials covering the full-stack web development ecosystem.

The portal is powered by a **custom GitHub Pages web app** with:
- 🔍 Real-time search across all files
- 🌗 Dark / Light theme toggle
- 📖 Markdown rendering with syntax highlighting
- 📊 Repository statistics view
- 📈 Reading progress tracker
- 📱 Fully responsive & mobile-friendly layout

## 🛠️ Tech Stack (Portal)

The documentation portal (`index.html`, `style.css`, `script.js`) is built with:

| Technology | Purpose |
|------------|---------|
| **Vanilla HTML / CSS / JS** | Core structure and logic |
| **Marked.js** | Markdown parsing |
| **DOMPurify** | HTML sanitization |
| **Highlight.js** | Code syntax highlighting |
| **KaTeX** | Math expression rendering |
| **Lucide Icons** | Icon set |
| **Google Fonts (Inter + Fira Code)** | Typography |
| **GitHub Pages** | Hosting & deployment |

## ✨ Portal Features

- ⚡ **Auto file discovery** — fetches the repo tree via GitHub API
- 🔍 **Ctrl + K** global search shortcut
- 🌗 **Dark & Light mode** — persisted in localStorage
- 🔑 **PAT support** — add a GitHub token to bypass API rate limits
- 📊 **Stats panel** — view counts by file type and total size
- 📖 **Markdown reader** — with heading navigation, code copy, and reading progress
- 📱 **Responsive sidebar** — collapsible on mobile

## 📌 How to Use

1. Visit the live portal: **[https://dileep-kumawat.github.io/Resources-Documentations/](https://dileep-kumawat.github.io/Resources-Documentations/)**
2. Browse files from the **sidebar** on the left
3. Use **Ctrl + K** to quickly search for any topic
4. Click any file to open it in the **reader view**
5. Toggle **dark/light mode** from the top-right header
6. Optionally add a **GitHub PAT** (🔑 icon) to avoid API rate limit issues
